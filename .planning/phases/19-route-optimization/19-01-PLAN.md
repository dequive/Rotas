# Plan 19-01: Route Optimization - Waypoint Sequencing, OSRM Integration & Deviation Alerts

## Objective
Implement multi-stop waypoint sequence optimization (OPTIM-01), OSRM distance matrix and route geometry integration with Haversine fallback (OPTIM-02), and GPS position route deviation alerting for >5km deviations (OPTIM-03).

## Requirements Coverage
- **OPTIM-01**: Multi-stop waypoint sequencing optimization using greedy nearest-neighbor TSP.
- **OPTIM-02**: Distance matrix & route geometry via OSRM with Haversine * 1.3 fallback.
- **OPTIM-03**: Route deviation alerting when vehicle GPS position is >5km off planned polyline corridor.

### 2. Waypoint Sequencing & OSRM Routing Service
#### [NEW] [backend/app/modules/trips/routing.py](file:///c:/Users/Quive/OneDrive/Documents/Rotas/backend/app/modules/trips/routing.py)
- `optimize_waypoint_sequence(origin: dict, destination: dict, stops: list[dict]) -> list[dict]`: Greedy nearest-neighbor TSP solver.
- `fetch_osrm_route(waypoints: list[dict]) -> dict`: Calls `http://router.project-osrm.org/route/v1/driving/...` with 5-second timeout.
- `calculate_haversine_fallback(waypoints: list[dict]) -> dict`: Fallback calculating sum of Haversine segment distances * 1.3.
- `perpendicular_distance_km(point: tuple[float, float], line_start: tuple[float, float], line_end: tuple[float, float]) -> float`: Flat-Earth perpendicular distance to polyline segment.
- `check_route_deviation(gps_point: tuple[float, float], route_geometry: list[tuple[float, float]], threshold_km: float = 5.0) -> bool`: Checks if GPS position is >5km off route.
