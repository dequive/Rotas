# Phase 13.5 Plan 01: Workshop Expansion Schema Migration Summary

**One-liner:** Single Alembic migration adding 14 new columns across 4 existing tables plus 3 new RLS-protected tables (workshop_staff_rates, tool_calibrations, spare_part_serial_items) for Phase 13.5 workshop operations expansion.

## What Was Built

Single migration file `backend/alembic/versions/a8f3b2c1d4e5_add_workshop_expansion.py` with revision ID `a8f3b2c1d4e5`, revising `f4c8a12d9b30`.

### ALTER TABLE changes (existing tables)

| Table | New Columns |
|---|---|
| `work_order_tasks` | `assigned_to UUID FK→users`, `estimated_minutes INT`, `actual_minutes INT` |
| `work_orders` | `labor_cost Numeric(14,2) NOT NULL DEFAULT 0` |
| `workshop_tools` | `category VARCHAR(40)`, `location VARCHAR(120)`, `serial_number VARCHAR(80)`, `purchase_date DATE`, `purchase_cost Numeric(10,2)`, `calibration_interval_days INT` |
| `spare_parts_inventory` | `category VARCHAR(40)`, `shelf_location VARCHAR(80)`, `supplier_name VARCHAR(160)`, `lead_time_days INT`, `reorder_quantity INT` |

### CREATE TABLE — new tables

**workshop_staff_rates**
- Columns: `id UUID PK`, `tenant_id UUID FK`, `user_id UUID FK→users`, `hourly_rate Numeric(10,2)`, `effective_from DATE`, `created_at TIMESTAMPTZ`
- Indexes: `ix_workshop_staff_rates_tenant_id`, `ix_workshop_staff_rates_user_id`
- RLS: ENABLED + FORCED + policy `rls_workshop_staff_rates` + GRANT to `rotas_app`

**tool_calibrations**
- Columns: `id UUID PK`, `tenant_id UUID FK`, `tool_id UUID FK→workshop_tools`, `calibrated_by UUID nullable`, `calibrated_at TIMESTAMPTZ`, `next_due_at TIMESTAMPTZ`, `notes TEXT`, `created_at TIMESTAMPTZ`
- Indexes: `ix_tool_calibrations_tenant_id`, `ix_tool_calibrations_tool_id`
- RLS: ENABLED + FORCED + policy `rls_tool_calibrations` + GRANT to `rotas_app`

**spare_part_serial_items**
- Columns: `id UUID PK`, `tenant_id UUID FK`, `part_id UUID FK→spare_parts_inventory`, `serial_number VARCHAR(120)`, `status VARCHAR(30) DEFAULT 'in_stock'`, `vehicle_id UUID nullable FK→vehicles ON DELETE SET NULL`, `installed_at TIMESTAMPTZ`, `scrapped_at TIMESTAMPTZ`, `notes TEXT`, `created_at TIMESTAMPTZ`
- Unique constraint: `uq_spare_part_serial_items_tenant_serial` on `(tenant_id, serial_number)`
- Indexes: `ix_spare_part_serial_items_tenant_part`, `ix_spare_part_serial_items_tenant_vehicle` (partial: WHERE vehicle_id IS NOT NULL)
- RLS: ENABLED + FORCED + policy `rls_spare_part_serial_items` + GRANT to `rotas_app`
