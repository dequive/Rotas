# Phase 15.1 Plan 08: Wave 3C — Document Checklist per Trip (OPDOC-05) Summary

## One-liner

`GET /trips/{id}/document-checklist` returns required vs present document types driven by `trip.is_international` and `trip.is_hazmat` — 4 domestic, 5 international, +1 hazmat.

## What Was Built

- `get_document_checklist()` service function — reads `trip.is_international` and `trip.is_hazmat` from DB, computes required types, queries present `transport_documents`
- `GET /trips/{trip_id}/document-checklist` router endpoint (read-only, DASHBOARD_ROLES)
- `is_international` boolean column added to `Trip` model + Alembic migration `9a3cc9a059814` (applied)
- `TripCreate` schema and `create_trip` service updated with `is_international` field
- Also added `POST /trips/{id}/declaracao-carga-perigosa` endpoint (hazmat guard + digital record)
