Key implementation details:

get_tenant_detail() cross-tenant read pattern for platform_support:
    When actor_role == PLATFORM_SUPPORT:
        await db.execute(text(f"SET LOCAL app.tenant_id = '{target_tenant_id}'"))
        tenant = await db.scalar(select(Tenant).where(Tenant.id == target_tenant_id))
        await record_platform_audit(db, actor_id=..., actor_role=..., action="tenant.read",
                                    target_tenant_id=target_tenant_id, resource_type="tenant",
                                    resource_id=target_tenant_id)
        # Do NOT reset app.tenant_id — SET LOCAL is transaction-scoped; resets on commit/rollback
    For platform_admin and platform_billing: direct query without SET LOCAL (they are not
    subject to tenant RLS since platform tables have no RLS, but Tenant table DOES have RLS).
    Therefore: all roles that read tenant data must use SET LOCAL app.tenant_id before querying
    the Tenant table, since it has RLS enabled. Set it to the target_tenant_id.

suspend_tenant() structure:
    tenant = await _require_tenant(db, tenant_id)  # raises 404 if not found
    if not tenant.is_active:
        raise ApiError("tenant_already_inactive", "Tenant is already inactive.", status_code=409)
    tenant.is_active = False
    await record_platform_audit(db, actor_id=actor.user_id, actor_role=actor.role,
                                action="tenant.suspend", target_tenant_id=tenant_id,
                                resource_type="tenant", resource_id=tenant_id)
    await db.commit()
    return {"id": tenant.id, "is_active": tenant.is_active}

_require_tenant() helper (module-private):
    Looks up Tenant by id using SET LOCAL app.tenant_id first (since Tenant table has RLS).
    Returns Tenant or raises ApiError 404.

create_platform_user():
    from app.core.passwords import hash_password
    existing = await db.scalar(select(PlatformUser).where(PlatformUser.email == email))
    if existing:
        raise ApiError("platform_user_email_conflict", "Email already registered.", status_code=409)
    user = PlatformUser(email=email, role=role, password_hash=hash_password(password))
    db.add(user)
    await record_platform_audit(db, actor_id=actor.user_id, actor_role=actor.role,
                                action="platform_user.created", resource_type="platform_user",
                                payload={"email": email, "role": role})
    await db.commit()
    await db.refresh(user)
    return {"id": user.id, "email": user.email, "role": user.role, "is_active": user.is_active,
            "created_at": user.created_at}
