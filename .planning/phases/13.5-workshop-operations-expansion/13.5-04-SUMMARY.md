## What Was Built

### workshop-api.ts — 5 new functions + 8 interfaces
- `loadSparePartsInventory()` — GET /api/v1/workshop/spare-parts?limit=500
- `loadLowStockParts()` — GET /api/v1/workshop/spare-parts/low-stock
- `loadTools()` — GET /api/v1/workshop/tools?limit=500
- `loadToolCalibrationHistory(toolId)` — GET /api/v1/workshop/tools/{id}/calibration-history
- `loadVehicleHistory(vehicleId, params?)` — GET /api/v1/vehicles/{id}/history with cursor pagination params
- Interfaces: SparePart, LowStockItem, LowStockResponse, WorkshopToolItem, ToolCalibrationEvent, VehicleHistoryEvent, VehicleHistoryResponse, VehicleHistoryParams

### PartsInventoryTable.tsx
- Columns: SKU / Nome / Stock Actual / Stock Mínimo / Custo Médio / Categoria / Prateleira / Estado
- Amber dot badge (`status="paragem" label="stock baixo"`) when current_quantity <= minimum_quantity
- Green dot badge (`status="concluida" label="OK"`) when stock is adequate
- IBM Plex Mono (`font-mono`) for SKU, quantities, costs; Manrope for labels

### ToolsTable.tsx
- Columns: Código / Nome / Estado / Calibração Próxima / Localização / Categoria / Alerta
- Red dot badge (`status="alerta" label="calibracao vence"`) when calibration_due_at <= now + 30 days
- `isCalibrationNearExpiry()` function computes 30-day threshold client-side
- IBM Plex Mono for code, dates; Manrope for labels

### /manutencao page.tsx — 4-tab layout
- Tab 1 "Ordens de Trabalho": all existing content (KPI cards, MaintenanceImminentPanel, work orders DataTable) preserved verbatim
- Tab 2 "Peças e Stock": `<PartsInventoryTable parts={parts} />`
- Tab 3 "Ferramentas": `<ToolsTable tools={tools} />`
- Tab 4 "Planos Preventivos": `<MaintenanceImminentPanel alerts={imminentAlerts} />`
- loadSparePartsInventory() and loadTools() added to the concurrent Promise.all fetch

### /viaturas/[id]/historico/page.tsx — Vehicle history timeline
- Server component, fetches /api/v1/vehicles/{id}/history?limit=50 via apiFetch
- Vertical timeline: amber-bordered icon circles (lucide icons per event_type), content cards
- Event date in IBM Plex Mono; title/label in Manrope
- Icons mapped: maintenance_request→Wrench, work_order→ClipboardList, fuel→Fuel, checklist→CheckSquare, incident→AlertTriangle, schedule→Calendar
- "← Viaturas" breadcrumb link
- Graceful empty state

### /viaturas/page.tsx — Ver Histórico link
- "Histórico" column added as new `<th>` + `<td>` in vehicle table
- Each row has `<Link href="/viaturas/${v.id}/historico">Ver Histórico</Link>` in --blue color
