## Notes on Deviations (non-blocking)

The following deviations were self-corrected by the implementation agent and do not affect goal achievement:

1. **Wave 3, SUMMARY-03**: `GET /vehicles/{vehicle_id}/history` already existed as an offset-paginated endpoint. Rather than replacing it, the implementation added cursor-paginated dispatch to the same route via query param presence detection. Both pagination modes coexist. Tests use `?types=` param to trigger the cursor path.

2. **Wave 5, SUMMARY-05**: `test_mechanic_cannot_access_billing` verifies `GET billing=200` (mechanic is in DASHBOARD_ROLES by design) and `POST billing=403`. The original spec said GET → 403, but the actual permission model is correct: mechanics can read dashboard data but cannot write billing.

3. **Wave 5, SUMMARY-05**: ApiError positional arg bug in `register_serial_item` was caught and fixed during testing (commit fb919e3). The duplicate serial 409 test passes.
