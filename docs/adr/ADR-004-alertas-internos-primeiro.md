# ADR-004 - Alertas Internos Antes de WhatsApp

## Estado

Aceite.

## Contexto

WhatsApp Cloud API exige conta Meta Business, templates aprovados e controlo de custo/ruido.

## Decisao

O MVP tera centro de alertas interno no dashboard. WhatsApp completo fica para fase posterior.

## Consequencias

- O backend deve gerar eventos de alerta desde cedo.
- O canal inicial e `dashboard`.
- WhatsApp sera adicionado quando eventos e prioridades estiverem validados.
