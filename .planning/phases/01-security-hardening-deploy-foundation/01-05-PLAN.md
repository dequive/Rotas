**Step 4 — Update apps/manager/app/lib/api.ts (D-18):**

Read the file first to see the exact current content. Then find every occurrence of
`process.env.ROTAS_API_BASE_URL` and replace it with `process.env.NEXT_PUBLIC_API_URL`.

The `NEXT_PUBLIC_` prefix is required because Next.js only exposes env vars to the browser
(and client-side build) if they are prefixed with `NEXT_PUBLIC_`. Server components and
API routes can also read `NEXT_PUBLIC_` vars. The old name `ROTAS_API_BASE_URL` was a
server-only var that Vercel would not pass through to the build output.

Example replacement (do NOT hardcode this — read the actual file):
```typescript
// BEFORE:
const baseUrl = process.env.ROTAS_API_BASE_URL ?? "http://localhost:8000";

// AFTER (D-18 per CONTEXT.md):
const baseUrl = process.env.NEXT_PUBLIC_API_URL ?? "http://localhost:8000";
```

Replace ALL occurrences in the file. Do not change any other logic.
