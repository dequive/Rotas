Create `apps/manager/app/despacho/page.tsx` as a Next.js 14 App Router page. This is a client component (`"use client"`).

The page must:

1. **On mount**: fetch `GET /api/v1/trips?status=completed&limit=100` to get a list of completed trips. For each trip, also attempt `GET /api/v1/trips/{id}/settlement` to load settlement state.

2. **Display a table** with columns:
   - Motorista (driver name — trip.driver_id displayed as truncated UUID until we have name, or fetch separately)
   - Viatura (vehicle plate — from trip or displayed as trip.vehicle_id)
   - Rota (trip.origin → trip.destination)
   - Estado (settlement status badge with colored dot: pending=amber, approved=green, rejected=red, no-settlement=grey)
   - Adiantamento (advance amount_mzn in IBM Plex Mono)
   - Despesas (total_costs_mzn in IBM Plex Mono)
   - Saldo (balance_mzn in IBM Plex Mono — amber text if ≥ 0, red text if < 0)
   - Ações (action buttons)

3. **Action buttons per row**:
   - If no settlement and no advance: "Emitir Despacho" button (amber, opens modal)
   - If advance issued but no settlement: "Calcular Liquidação" button (calls POST /settlement)
   - If settlement pending: "Aprovar" (green) + "Rejeitar" (red) buttons
   - If settlement approved: "Download PDF" link (GET /settlement/pdf triggers download)

4. **"Emitir Despacho" modal**:
   - Input: Valor do Adiantamento (MZN) — number input, required
   - Input: Notas (textarea, optional)
   - Submit calls `POST /api/v1/trips/{trip_id}/advance` with `Idempotency-Key: crypto.randomUUID()` header
   - On success: close modal, refresh trip list

5. **"Rejeitar" flow**: inline prompt (window.prompt or small inline form) asking for rejection reason, then calls POST /settlement/reject.

6. **Design tokens**:
   - Page title: "Despacho" in Manrope font, bold
   - Monetary values: IBM Plex Mono font-family inline style or Tailwind font-mono
   - Status badge pattern: `<span>` with rounded-full, colored background, small colored dot before text
   - Positive balance (≥ 0): amber color `#f59e0b`
   - Negative balance (< 0): red color `#ef4444`
   - "Emitir Despacho" button: amber background `#f59e0b`

Use `apiFetch` from `@/app/lib/api` for all HTTP calls. Handle loading state with a simple "Carregando..." text. Handle errors with `alert()` for simplicity (no toast library confirmed).
