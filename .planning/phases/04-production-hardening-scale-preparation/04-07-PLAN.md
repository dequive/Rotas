Create the file `backend/railway.toml` with the following content:

```toml
# ROTAS Backend — Railway deployment configuration
# D-12: Gunicorn multi-worker FastAPI (4 workers, UvicornWorker class)
# D-13: ARQ worker runs as a separate Railway service

[deploy]
# Run Alembic migrations before new version accepts traffic
# WARNING: update path must be app.main:app — verify module path matches project layout
preDeployCommand = "alembic upgrade head"
startCommand = "gunicorn -k uvicorn.workers.UvicornWorker -w 4 --timeout 30 --bind 0.0.0.0:$PORT app.main:app"
healthcheckPath = "/health"
healthcheckTimeout = 300
restartPolicyType = "ON_FAILURE"
restartPolicyMaxRetries = 5

# Environment variables required at deploy (must be set in Railway dashboard):
# DATABASE_URL          — PostgreSQL connection string (rotas_app role after RLS is set up)
# ADMIN_DATABASE_URL    — PostgreSQL connection string (rotas_admin role, BYPASSRLS) for ARQ worker
# JWT_SECRET_KEY        — JWT signing secret (minimum 32 chars)
# ENVIRONMENT           — "production"
# CORS_ORIGINS          — JSON array of allowed origins e.g. ["https://rotas.vercel.app"]
# REDIS_HOST            — Railway Redis internal host
# REDIS_PORT            — 6381 (or Railway-assigned port)
```

Note: Railway uses `$PORT` for the assigned port. The `app.main:app` module path assumes gunicorn is run from within the `backend/` directory. Verify with `cd backend && gunicorn --check-config -k uvicorn.workers.UvicornWorker app.main:app` locally.

**Step 2: Tune database engine for multi-worker safety (Pitfall 4)**

In `backend/app/database.py`, update the engine creation to add pool parameters:

```python
from app.config import get_settings
settings = get_settings()

# Pool tuning for Gunicorn multi-worker (D-12 / Pitfall 4)
# 4 workers × pool_size=2 × max_overflow=3 = max 20 connections
# Prevents OOM on Railway 2GB instance
_pool_kwargs = {}
if settings.environment == "production":
    _pool_kwargs = {"pool_size": 2, "max_overflow": 3}

engine = create_async_engine(
    settings.database_url,
    pool_pre_ping=True,
    **_pool_kwargs,
)
```
