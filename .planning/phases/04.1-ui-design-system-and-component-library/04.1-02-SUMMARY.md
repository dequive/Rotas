## What Was Done

### Task 1: StatusBadge

Created `StatusBadge` with 25 status key mappings covering all entity states in the application:
- Trip/vehicle operational: em-rota, paragem, descarga, alerta, aguarda, concluida, cancelada, planeada
- Billing: billed, billable, not_billable, waiver_required, draft, issued
- Document/compliance: valid, expiring_soon, expired
- Maintenance/work order: open, in_progress, completed
- Dispatch/clearance: pending, approved, blocked

Each status maps to dot color (bg-success, bg-warning, bg-error, bg-info, bg-amber), background (bg-success-bg, bg-warning-bg, bg-error-bg, bg-info-bg, bg-amber-light), and text color tokens from the DESIGN.md palette. Unknown status strings fall back to neutral gray to avoid runtime crashes when new API states are added.

The colored dot is a `<span className="h-1.5 w-1.5 rounded-full">` — React cannot express `::before` pseudo-elements in JSX. DESIGN.md says "dot colorido" and this is the correct implementation.

Replaces the legacy `.badge.green/.orange/.red/.blue/.cyan` CSS class pattern used in ControlTowerOverview, BillingTripActions, FleetComplianceBoard, FleetHistoryBoard.

### Task 2: KpiCard

Created `KpiCard` with:
- Value in `font-mono text-[26px] font-medium tabular-nums` — IBM Plex Mono per DESIGN.md specification for monetary/numeric values
- 6 semantic color variants (default, amber, error, success, warning, info) via static lookup object
- Trend indicator with directional arrows (↑↓–), positive/negative color logic, and `positiveIsUp` flag for cost metrics where "up" means bad
- Skeleton loading state with `animate-pulse` (no external dependency on Skeleton component)
- Label in `text-[11px] font-semibold uppercase tracking-wide text-muted` per DESIGN.md KPI card spec

Replaces `.tower-metric`, `.transport-kpi`, `.fuel-metric`, `.panel.metric` legacy CSS patterns.

### Task 3: PageHeader, SectionHeader, WorkQueue

**PageHeader:** H1 (Manrope 700 28px) with optional eyebrow (11px UC tracking-widest), description, right-aligned actions slot, and meta slot below title. Replaces `.operational-heading`, `.page-header`, `.topbar`.

**SectionHeader:** Section title (14px 600) with optional count badge (tabular-nums), optional description, and right-aligned actions slot. Uses `bg-surface-2 border-b border-border` background. Replaces `.section-header`, `.domain-heading`.

**WorkQueue:** Card-based work queue with colored icon header, item list with `font-mono text-[11px]` reference spans, hover states, and empty state. The `toneConfig` static lookup object resolves tone → Tailwind classes (e.g., `border-l-success`, `bg-success-bg`, `text-success`) — never dynamic string concatenation like `border-l-${tone}` which Tailwind's static scanner would purge from the production build. Replaces `.queue`, `.worklist` CSS patterns.
