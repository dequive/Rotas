- `na` / other → fill `_MUTED` text `_WHITE`

2. **Metadata bar** (fill `_SOFT`, 9mm):
   Tipo Inspecção | Template | Data Início | Data Fim | Duração (seconds / 60 formatted as
   "Xmin" or "—"). Right-aligned Bold: "INSPECÇÃO DE VIATURA".

3. **Items grid** — 2 items per row to conserve space:
   - `section_header("ITENS DE INSPECÇÃO")`
   - Get items list from `template.items` if template else `[]`.
     For each item, lookup response from `checklist.responses.get(item.id or item['id'], {})`.
   - Each item cell is 90mm wide (2 per row, gap 0mm). Cell height 12mm.
     Inside cell: item label (Bold 7pt, first 36 chars truncated + "…" if longer);
     response answer (Regular 7pt, up to 30 chars); state pill (Mini rect 18mm×4mm, filled
     with state colour, text "OK"/"NOK"/"N/A" in White 6pt Bold).
   - After every 2 items, move Y to next row.

4. **Observations block** (only if any response has notes):
   `section_header("OBSERVAÇÕES")`;
   For each item with notes: `kv_row(item_label, notes_text)`.

5. **Signature block**:
   `section_header("ASSINATURA DO MOTORISTA")`;
