## Goal

Build the full CRUD layer for the third-party module: Pydantic schemas, service functions following the drivers/clients pattern, and a registered HTTP router exposing all endpoints under `/api/v1/third-party`.

### Task 2 — Service layer

**File:** `backend/app/modules/third_party/service.py`

Follow the drivers/clients pattern exactly: `serialize_*`, `_require_*`, `record_audit_log` in same transaction before `db.commit()`. Implement these functions:

**Serialize helpers:**
- `serialize_third_party(tp: ThirdParty) -> dict` — returns all ThirdParty fields as dict
- `serialize_role(r: ThirdPartyRole) -> dict`
- `serialize_supplier_profile(sp: SupplierProfile) -> dict`
- `serialize_service_provider_profile(spp: ServiceProviderProfile) -> dict`

**Guard helpers:**
- `async def _require_third_party(db, tenant_id, tp_id) -> ThirdParty` — raises `ApiError("third_party_not_found", ..., 404)` if not found or wrong tenant
- `async def _nuit_exists(db, tenant_id, nuit, *, exclude_id=None) -> bool`

**Core CRUD:**
- `async def create_third_party(db, tenant_id, payload: ThirdPartyCreate, *, actor_id) -> dict`
  - Check `_nuit_exists` if `payload.nuit` is set, raise `ApiError("third_party_nuit_duplicate", ..., 409)` if already exists
  - Pattern: `db.add(tp)` → `await db.flush()` → `await db.refresh(tp)` → `await record_audit_log(...)` with `action="third_party.created"` → `await db.commit()` → `await db.refresh(tp)` → return `serialize_third_party(tp)`
- `async def list_third_parties(db, tenant_id, *, status: str | None = None, limit=50, offset=0) -> list[dict]`
- `async def get_third_party(db, tenant_id, tp_id) -> dict`
- `async def update_third_party(db, tenant_id, tp_id, payload: ThirdPartyUpdate, *, actor_id) -> dict`
  - Capture `old_values = serialize_third_party(tp)` before patching
  - Only update fields that are not None in payload
  - Audit action: `"third_party.updated"`

**Role CRUD:**
- `async def create_role(db, tenant_id, tp_id, payload: RoleCreate, *, actor_id) -> dict`
  - Validate `payload.role_type in VALID_ROLE_TYPES` — raise `ApiError("invalid_role_type", ..., 422)` if not
  - Check for existing role with same `(third_party_id, role_type)` — raise `ApiError("role_already_assigned", ..., 409)` if exists
  - Audit action: `"third_party.role_assigned"`
- `async def list_roles(db, tenant_id, tp_id) -> list[dict]`

**Profile upsert (insert or update):**
- `async def upsert_supplier_profile(db, tenant_id, tp_id, payload: SupplierProfileCreate, *, actor_id) -> dict`
  - `SELECT` existing profile for `third_party_id == tp_id`; if exists, UPDATE; if not, INSERT
  - Audit action: `"third_party.supplier_profile_updated"`
- `async def upsert_service_provider_profile(db, tenant_id, tp_id, payload: ServiceProviderProfileCreate, *, actor_id) -> dict`
  - Same upsert pattern
  - Audit action: `"third_party.service_provider_profile_updated"`

**Provinces:**
- `async def list_provinces(db) -> list[dict]`
  - `SELECT * FROM mz_provinces ORDER BY name` — no tenant filter

### Task 3 — Router + main.py registration

**File:** `backend/app/modules/third_party/router.py`

```python
from uuid import UUID
from fastapi import APIRouter, Depends, Query
from sqlalchemy.ext.asyncio import AsyncSession
from app.database import get_session
from app.modules.auth.dependencies import get_current_principal, require_roles
from app.modules.third_party import service
from app.modules.third_party.schemas import (
    ThirdPartyCreate, ThirdPartyUpdate,
    RoleCreate, SupplierProfileCreate, ServiceProviderProfileCreate,
)

router = APIRouter(prefix="/third-party", tags=["third-party"])

# Province reference (no auth needed — platform reference data)
@router.get("/provinces")
async def list_provinces(db: AsyncSession = Depends(get_session)):
    return await service.list_provinces(db)

# Third party CRUD
@router.post("", status_code=201)
async def create_third_party(
    payload: ThirdPartyCreate,
    db: AsyncSession = Depends(get_session),
    principal=Depends(get_current_principal),
):
    require_roles(principal, {"owner", "admin", "manager"})
    return await service.create_third_party(
        db, principal.tenant_id, payload, actor_id=principal.user_id
    )

@router.get("")
async def list_third_parties(
    status: str | None = Query(None),
    limit: int = Query(50, ge=1, le=200),
    offset: int = Query(0, ge=0),
    db: AsyncSession = Depends(get_session),
    principal=Depends(get_current_principal),
):
    return await service.list_third_parties(
        db, principal.tenant_id, status=status, limit=limit, offset=offset
    )

@router.get("/{tp_id}")
async def get_third_party(
    tp_id: UUID,
    db: AsyncSession = Depends(get_session),
    principal=Depends(get_current_principal),
):
    return await service.get_third_party(db, principal.tenant_id, tp_id)

@router.patch("/{tp_id}")
async def update_third_party(
    tp_id: UUID,
    payload: ThirdPartyUpdate,
    db: AsyncSession = Depends(get_session),
    principal=Depends(get_current_principal),
):
    require_roles(principal, {"owner", "admin", "manager"})
    return await service.update_third_party(
        db, principal.tenant_id, tp_id, payload, actor_id=principal.user_id
    )

# Roles
@router.post("/{tp_id}/roles", status_code=201)
async def create_role(
    tp_id: UUID,
    payload: RoleCreate,
    db: AsyncSession = Depends(get_session),
    principal=Depends(get_current_principal),
):
    require_roles(principal, {"owner", "admin", "manager"})
    return await service.create_role(
        db, principal.tenant_id, tp_id, payload, actor_id=principal.user_id
    )

@router.get("/{tp_id}/roles")
async def list_roles(
    tp_id: UUID,
    db: AsyncSession = Depends(get_session),
    principal=Depends(get_current_principal),
):
    return await service.list_roles(db, principal.tenant_id, tp_id)

# Supplier profile
@router.put("/{tp_id}/supplier-profile", status_code=200)
async def upsert_supplier_profile(
    tp_id: UUID,
    payload: SupplierProfileCreate,
    db: AsyncSession = Depends(get_session),
    principal=Depends(get_current_principal),
):
    require_roles(principal, {"owner", "admin", "manager"})
    return await service.upsert_supplier_profile(
        db, principal.tenant_id, tp_id, payload, actor_id=principal.user_id
    )

# Service provider profile
@router.put("/{tp_id}/service-provider-profile", status_code=200)
async def upsert_service_provider_profile(
    tp_id: UUID,
    payload: ServiceProviderProfileCreate,
    db: AsyncSession = Depends(get_session),
    principal=Depends(get_current_principal),
):
    require_roles(principal, {"owner", "admin", "manager"})
    return await service.upsert_service_provider_profile(
        db, principal.tenant_id, tp_id, payload, actor_id=principal.user_id
    )
```
