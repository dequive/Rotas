## Color

Source: DESIGN.md `## Color` + `globals.css` `:root`. Restrained — 1 amber accent + neutrals.

| Role | Hex | CSS var | Usage |
|------|-----|---------|-------|
| Dominant (60%) | `#f1f5f9` | `--bg` | Page background (`bg-[var(--bg)]`) |
| Secondary (30%) | `#ffffff` / `#f8fafc` | `--surface` / `--surface-2` | Cards, table bg, modal, input bg |
| Sidebar | `#0f1623` | `--sidebar-bg` | Navigation sidebar |
| Accent — amber (10%) | `#f59e0b` | `--amber` | Reserved list below |
| Accent — blue | `#2563eb` | `--blue` | Links, focus rings, active table rows |
| Semantic — success | `#16a34a` | `--success` | Active client badge, positive trend |
| Semantic — warning | `#d97706` | `--warning` | Credit limit approaching (80–99% used) |
| Semantic — error | `#dc2626` | `--error` | Credit limit exceeded (≥100%), form errors |
| Semantic — info | `#0891b2` | `--info` | Inactive/pending client badge |

**Amber accent reserved for:**
- Sidebar active item left border (`border-amber`) and active background
- Primary CTA button background (`bg: var(--amber)`, `color: #0f1623`) — "Novo Cliente" and "Guardar Cliente" / "Guardar Alterações"
- KPI card value when semantic = `amber` (revenue-class metrics only — not applicable in Phase 5)
- The amber accent is NOT used for credit limit warnings — those use `--warning` (orange) and `--error` (red)

**Credit limit warning color rule (CLI-02):**
- 0–79% of limit used: no indicator shown
- 80–99% of limit used: `--warning-bg` (`#fffbeb`) banner + `--warning` (`#d97706`) text + warning icon
- ≥100% of limit used (exceeded): `--error-bg` (`#fef2f2`) banner + `--error` (`#dc2626`) text + alert icon
- These are non-blocking visual warnings only — no action is prevented

**Client status badge color mapping:**
- Activo → `success` (green dot)
- Inactivo → `error` (red dot)  
- Sem contratos → `info` (cyan dot)

- Displays: `{trading_name}` as primary, `NUIT: {nuit}` as secondary (IBM Plex Mono 11px)

## Surface Specifications

### Surface 1: `/clientes` — Client Registry List

**Primary focal point:** The "Novo Cliente" amber CTA button in the PageHeader right slot.

**Layout:**
- `SidebarLayout active="clientes"` (new nav key — see Sidebar section below)
- `PageHeader` with `title="Clientes"`, `description="{N} clientes registados"`, `actions=<Button>Novo Cliente</Button>`
- KPI strip: 4 × `KpiCard` in `grid grid-cols-4 gap-4 mb-6`
- Search bar: `Input` with `Search` icon, `placeholder="Pesquisar por nome, NUIT ou cidade…"`, `className="max-w-sm"`, client-side filter
- `DataTable` with `SectionHeader` wrapping the panel

**KPI cards (4):**
1. Label: "CLIENTES ACTIVOS" — value: count of status=active — semantic: default
2. Label: "SALDO EM ABERTO" — value: sum of outstanding balances in MZN (IBM Plex Mono) — semantic: error if total > 0, else default
3. Label: "LIMITE EXCEDIDO" — value: count of clients with balance > credit_limit — semantic: error if > 0, else default
4. Label: "CONTRATOS ACTIVOS" — value: count of active contracts across all clients — semantic: default

**Table columns:**
| Column | Content | Notes |
|--------|---------|-------|
| Cliente | `trading_name` (Manrope 500 `--ink`) + `legal_name` (13px `--muted`) below | Primary identity |
| NUIT | `MonoCell` IBM Plex Mono 13px | Tax ID |
| Cidade | Plain text 13px | City |
| Prazo pgto. | "30 dias" / "45 dias" / "60 dias" / "90 dias" | Payment terms |
| Limite de crédito | `MonoCell` MZN value | `--muted` if not set |
| Estado | `StatusBadge` with client status key | activo / inactivo |
| Acções | `RotasTableActionsCell` with "Ver" link → `/clientes/[id]`, "Editar" button | Sticky right |

**Empty state:**
- Icon: `Users` (lucide)
- Title: "Sem clientes registados"
- Description: "Crie o primeiro cliente para associar contratos e faturas."
- Action: `<Button>Novo Cliente</Button>` (primary)

### Surface 2: `/clientes/[id]` — Client Detail

**Layout:**
- `SidebarLayout active="clientes"`
- `PageHeader` with `title={client.trading_name}`, `eyebrow="Cliente"`, `actions=<Button variant="outline">Editar</Button>`
- Two-column info card + credit warning strip
- Two panels below: "Contratos" and "Faturas emitidas"

**Client info card** (`bg-surface border border-border rounded-lg p-4`):
Grid 2-col: left column has NUIT, email, phone, address, city; right column has payment terms, credit limit, outstanding balance, payment_terms_days.

**Credit limit warning strip** (appears between info card and panels, full-width):
- Hidden when outstanding_balance < credit_limit × 0.80

**Contracts panel:**
- `SectionHeader` title="Contratos" count={contracts.length} actions=link to `/contratos?client_id={id}`

**Invoices panel:**

## Client Create/Edit Modal (`ClientFormModal`)

Create `app/components/ClientFormModal.tsx` following the same pattern as `ContractFormModal`.

**Trigger:** Primary button "Novo Cliente" (create mode); ghost/outline "Editar" (edit mode).

**Modal width:** 540px (standard `.modal`)

**Form fields** (in `.modal-form`):

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| Nome comercial | `Input` | Yes | `trading_name` — main display name |
| Nome legal | `Input` | No | `legal_name` — full registered name |
| NUIT | `Input` | Yes | 9-digit tax ID; IBM Plex Mono hint text via `className`; pattern: `[0-9]{9}` |
| Morada | `Input` | No | Street address |
| Cidade | `Input` | No | City |
| Telefone | `Input` | No | Phone with `+258` placeholder |
| Email | `Input` type=email | No | Billing contact email |
| Prazo de pagamento | `Select` | Yes | Options: 30 dias / 45 dias / 60 dias / 90 dias |
| Limite de crédito | `Input` type=number | No | In MZN; `0` means "sem limite"; `placeholder="0 = sem limite"` |

**Two-column layout** for narrow fields using `.form-row` (grid 2-col):
- Row 1: NUIT + Telefone
- Row 2: Morada (full width)
- Row 3: Cidade + Email
- Row 4: Prazo de pagamento + Limite de crédito

**Modal actions** (`.modal-actions`):
- Cancel: `<button className="secondary-btn">Cancelar</button>`
- Submit (create mode): `<button className="primary-btn">Guardar Cliente</button>` (amber background) / disabled + spinner while saving
- Submit (edit mode): `<button className="primary-btn">Guardar Alterações</button>` (amber background) / disabled + spinner while saving

**Deactivate action** (edit mode only, positioned left in modal-actions):
- `<button className="action-btn" style={{color:'var(--error)'}}>Desactivar cliente</button>`
- No confirmation dialog — inline toggle only (status: active → inactive); not a destructive delete

## Implementation Notes for Executor

1. **Sidebar change**: Add `{ key: "clientes", label: "Clientes", href: "/clientes", icon: Building2 }` as first item in Financeiro section in `SidebarLayout.tsx`. Import `Building2` from lucide-react.

2. **ClientCombobox pattern**: Follow `Popover` + `Command` pattern. See shadcn combobox docs. The trigger is a `Button variant="outline"` that shows selected value or placeholder. The `Command` component handles search. Fetch happens once on popover open with `useEffect`.

3. **ContractFormModal**: The existing modal has a `client_name` text input. Replace it with `ClientCombobox`. Keep `client_name` as a hidden read-only field (for display in the existing contracts table until migration completes — CLI-03 keeps it as denormalized cache). The form submits `client_id` (UUID) to `POST /api/v1/contracts` or `PATCH /api/v1/contracts/{id}`.

4. **Invoice number display**: Use `MonoCell` for `AAAA/NNNN` format everywhere (invoice table on client detail, cobrança list). Never render invoice numbers in Manrope.

5. **KPI data fetching**: The 4 KPIs on `/clientes` may be fetched from a single `GET /api/v1/clients/summary` endpoint or computed client-side from the clients list response. The executor should confirm which endpoint exists before choosing the approach.

6. **Credit limit percentage**: Computed client-side as `(outstanding_balance / credit_limit) * 100`. If `credit_limit === 0` or `null`, treat as "sem limite" — no warning shown ever.

7. **StatusBadge new key**: Add `'activo'` and `'inactivo'` to `statusConfig` in `StatusBadge.tsx` if not already present. Map to `success` and `error` tones respectively.

8. **Modal submit button label**: Render "Guardar Cliente" in create mode and "Guardar Alterações" in edit mode. Use a `mode` prop on `ClientFormModal` to switch the label.
