# Phase 4.1 Plan 06: Domain Board Migration (Wave 4) Summary

Migrated 4 domain board components — FuelControlBoard, FleetHistoryBoard, TransportCargoBoard, CostMarginBoard — to use shared design system primitives. The highest-impact change: CostMarginBoard's margin KPI now renders in IBM Plex Mono with `semantic="error"` (red) for negative margins and `semantic="success"` (green) for positive margins, making financial health instantly visible without reading the number.

## What Was Done

### Task 1: FuelControlBoard + FleetHistoryBoard

**FuelControlBoard:**
- `<section className="domain-section">` + `<div className="domain-heading">` → `PageHeader` (eyebrow="Combustível Interno", title, description, actions slot with DataSourceBadge)
- Local `FuelMetric` component replaced by 4 `KpiCard` instances in a `grid grid-cols-2 md:grid-cols-4 gap-3` grid. "Abaixo do mínimo" uses `semantic="error"` when count > 0.
- `TankStatus` badge: `<span className="badge orange/green">` → `<StatusBadge status="alerta/em-rota" label="Repor/Normal" />`
- Tank average cost: plain `formatMoney()` string → `<MoneyCell value={tank.averageUnitCost} semantic="cost" />/L`
- `<p className="empty-state">` → `<EmptyStateInline label="..." />`
- `bg-panel` / `border-line` → `bg-surface` / `border-border` (design token alignment)
- Inline `data-source` div removed; DataSourceBadge passed to PageHeader actions slot

**FleetHistoryBoard:**
- `domain-section` + `domain-heading` → `PageHeader` with DataSourceBadge in actions
- Vehicle plate in `<h3>` wrapped with `<MonoCell size="sm">` for IBM Plex Mono
- Reference IDs in timeline events → `<MonoCell size="xs">`
- `<p className="empty-state">` → `<EmptyStateInline label="..." />`
- `bg-panel` / `border-line` → `bg-surface` / `border-border`
- `sourceToneClass` updated: `bg-cyan` → `bg-info`, `bg-green` → `bg-success`, `bg-orange` → `bg-warning` (design token alignment)

### Task 2: TransportCargoBoard + CostMarginBoard

**TransportCargoBoard:**
- `domain-section` + `domain-heading` → `PageHeader`. "Em fechamento" state + "Avaliar SLA" button moved to PageHeader actions slot
- Table-based KPI list (6 `TransportKpiRow` in shadcn Table) replaced with 6 `KpiCard` instances in a responsive grid (`grid-cols-2 md:grid-cols-3 lg:grid-cols-6`). Semantic coloring: `dispatchPending > 0 → warning`, `incidentsOpen > 0 → error`, etc.
- `TransportQueue.items.length === 0` plain paragraph → `<EmptyStateInline label={emptyLabel} />`
- Unused `Table, TableBody, TableCell, TableHead, TableHeader, TableRow` shadcn import removed
- `bg-panel` / `border-line` → `bg-surface` / `border-border`

**CostMarginBoard (highest impact):**
- Local `CostKpi` component removed entirely (15 lines)
- 4 `KpiCard` replacements with semantic mapping:
  - "Custo real" → `semantic="default"`
  - "Receita" → `semantic="success"` (green IBM Plex Mono)
  - "Margem" → `semantic={marginTotal < 0 ? "error" : "success"}` (red/green IBM Plex Mono — the key financial signal)
  - "Por reconciliar" → `semantic="warning"`
- Two `<article className="bg-panel ... section-header">` panels → `<article className="bg-surface border border-border rounded-lg overflow-hidden">` with `<SectionHeader title count />` header
- `<p className="empty-state">` → `<EmptyStateInline label="..." />`
- Plate numbers in `NegativeMarginItem` and `DespachoPendingItem` → `<MonoCell size="xs">`
- Trip reference IDs → `<MonoCell size="xs" className="font-semibold">`
- Monetary values in cost breakdown DL → `<MoneyCell value={...} semantic="cost/revenue/error" />`
