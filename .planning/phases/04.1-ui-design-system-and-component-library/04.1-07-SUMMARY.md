# Phase 04.1 Plan 07: Main Dashboard Page Billing Section Migration Summary

Migrated the billing section of `app/page.tsx` — the main manager dashboard — from legacy CSS class patterns to shared design system primitives. IBM Plex Mono is now applied to billing KPI values, plate numbers, monetary amounts in the billing table, and document totals, making financial data scannable at a glance on the page every manager sees on login.

## What Was Built

### page.tsx — Billing Section

**Replaced legacy patterns:**

- `.section-divider` + `.title` + `.eyebrow` div block → inline Tailwind eyebrow span + h2 + p with `px-6 mt-8 mb-4` wrapper
- `.topbar` + `.toolbar` + `.tool-btn` + `.icon-btn` → `inline-flex` button elements with Tailwind border/hover tokens
- `.data-source.${source}` div with `Link2` icon → `DataSourceBadge source={source} message={...}` component
- `.billing-kpi-grid` + 4 `.panel.metric` divs (red-line/orange-line/cyan-line/green-line) → 4 `KpiCard` instances in `grid grid-cols-2 md:grid-cols-4 gap-3`
  - "Sem contrato" uses `semantic={count > 0 ? "error" : "default"}` — IBM Plex Mono red when action needed
  - "A validar descarga" uses `semantic="warning"` — amber
  - "Prontas a cobrar" uses `semantic="info"` — cyan
  - "Valor controlado" uses `semantic="success"` — green IBM Plex Mono
- `.queue-grid` + `.queue` + `.queue-list` per-status articles → `WorkQueue` component mapped via `statusOrder.map()` with tone cast
- `.content.billing-content` + `.panel` + `.section-header` + `.table-wrap` + `.table` → `bg-surface border border-border rounded-lg` section with `SectionHeader title count` header + styled `<table>`
  - `.plate` span with `Truck` icon → `inline-flex` span + `MonoCell size="sm"` for IBM Plex Mono plate numbers
  - `.muted-line` spans → `flex flex-col` with `text-[12px] text-muted` secondary lines
  - `.route` span with `Route` icon → `inline-flex items-center gap-1.5` with muted icon
  - `.badge.${meta.tone}` → `StatusBadge status={trip.status} label={meta.label}` with label override
  - `money(trip.amount)` string → `MoneyCell value={trip.amount ?? 0} semantic="revenue|default"` (IBM Plex Mono)
- `.documents-panel` + `.document` article grid → `bg-surface border border-border rounded-lg` section with `SectionHeader title description` + `divide-y divide-border` article list
  - Document reference `<strong>` → `MonoCell size="sm"` for IBM Plex Mono
  - `.badge.green/.blue` → `StatusBadge status="issued|draft" label={document.status}`
  - `money(document.amount)` string → `MoneyCell value={document.amount ?? 0} semantic="revenue"`

**Removed imports:** `Link2` from lucide-react (now inside DataSourceBadge)

**Added imports:**
