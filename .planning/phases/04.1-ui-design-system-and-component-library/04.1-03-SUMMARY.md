## What Was Done

### Task 1: MonoCell + EmptyState

**MonoCell** — the highest-impact single change for DESIGN.md compliance. Vehicle plates (MQ-42-AB), trip IDs, document numbers, and monetary values currently render in Manrope across all 15 table-heavy components. MonoCell wraps any value that must use IBM Plex Mono. Three size variants: `xs` (11px), `sm` (12px default), `base` (13px).

**MoneyCell** — convenience wrapper over MonoCell specifically for MZN amounts. Uses `pt-MZ` locale for `toLocaleString` (correct Mozambique decimal formatting), `minimumFractionDigits: 2` for consistent alignment. Four semantic variants: `default` (text-ink), `revenue` (text-success), `cost` (text-ink-2), `error` (text-error).

**EmptyState** — full-page empty state for zero-data views. Accepts optional `LucideIcon`, title (required), description, and action slot (for a CTA button). Always explains why the area is empty and what will appear.

**EmptyStateInline** — compact variant for embedding inside a table `<tbody>` when there are no rows. Default label "Sem registos" (Portuguese).

### Task 2: DataTable + DataSourceBadge

**DataTable** — thin wrapper around shadcn `<Table>` that adds ROTAS conventions without introducing a full data-grid library. Key additions:
- `overflow-x-auto` outer div with `rounded-lg border border-border bg-surface` card shell
- `isEmpty` + `emptyLabel` props to render `EmptyStateInline` when no rows
- `RotasTableHeader` — 11px uppercase tracking-wide muted column headers (matches DESIGN.md table spec)
- `RotasTableRow` — hover:bg-surface-2 with 75ms transition, border-b border-border
- `RotasTableCell` — px-3 py-2.5 text-[13px] text-ink
- `RotasTableActionsCell` + `RotasTableActionsHeader` — sticky right-0 with left drop shadow for pinned action columns

Re-exports all shadcn table primitives (`Table`, `TableBody`, `TableHeader`, `TableRow`, `TableCell`, `TableHead`) so callers only need one import.

**DataSourceBadge** — replaces the `.data-source.api` / `.data-source.fallback` CSS class pattern used in `ControlTowerOverview.tsx`. Three states:
- `api` — Gauge icon, text-success, bg-success-bg, "Dados em tempo real."
- `cache` — Gauge icon, text-info, bg-info-bg, "Dados em cache (< 60s)."
- `fallback` — WifiOff icon, text-warning, bg-warning-bg, "A mostrar dados de fallback — API indisponível."
