**Step 2 — Create railway.toml at repo root:**

```toml
# railway.toml — Railway deployment configuration
# D-14/D-15/D-16 per CONTEXT.md: Railway, preDeployCommand, uvicorn start command
# Documentation: https://docs.railway.com/config-as-code/reference

[deploy]
# DEPLOY-04: Alembic migrations run BEFORE new server version accepts traffic.
# alembic/env.py reads DATABASE_URL from environment (get_settings() → config.set_main_option).
# The env.py automatically converts postgresql+asyncpg:// → postgresql+psycopg:// for Alembic.
# IMPORTANT: Set DATABASE_URL in Railway env vars as postgresql+asyncpg://... (asyncpg scheme),
# NOT the Railway-default postgresql:// scheme. env.py handles the conversion for Alembic.
preDeployCommand = ["alembic upgrade head"]

# DEPLOY-02: Start command runs from repo root. backend/__init__.py makes this module path work.
# Railway sets $PORT automatically — do not hardcode the port.
startCommand = "uvicorn backend.app.main:app --host 0.0.0.0 --port $PORT"

# Health check: Railway waits for /health to return 200 before routing traffic.
healthcheckPath = "/health"
healthcheckTimeout = 300

restartPolicyType = "ON_FAILURE"
restartPolicyMaxRetries = 5
```
