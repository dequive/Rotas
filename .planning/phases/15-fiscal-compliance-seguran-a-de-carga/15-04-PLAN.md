The `document` object now has `.subtotal`, `.tax_amount`, and `.total_amount`. The `document.iva_rate` field (or a calculation from items) determines the rate label.

Implementation approach using fpdf2:
```python
# totals block — three lines
def _format_amount(val):
    return f"{float(val):,.2f} {document.currency}"

iva_pct = int(float(document.iva_rate or 0) * 100) if document.iva_rate else ""
iva_label = f"IVA ({iva_pct}%)" if iva_pct else "IVA"

pdf.set_font("DejaVu", size=9)
# SUBTOTAL row
pdf.cell(w=col1_w, h=6, text="SUBTOTAL", align="R")
pdf.cell(w=col2_w, h=6, text=_format_amount(document.subtotal), align="R", new_x=XPos.LMARGIN, new_y=YPos.NEXT)
# IVA row
pdf.cell(w=col1_w, h=6, text=iva_label, align="R")
pdf.cell(w=col2_w, h=6, text=_format_amount(document.tax_amount), align="R", new_x=XPos.LMARGIN, new_y=YPos.NEXT)
# TOTAL COM IVA row (bold)
pdf.set_font("DejaVu", style="B", size=10)
pdf.cell(w=col1_w, h=7, text="TOTAL COM IVA", align="R")
pdf.cell(w=col2_w, h=7, text=_format_amount(document.total_amount), align="R", new_x=XPos.LMARGIN, new_y=YPos.NEXT)
```

The exact column widths must match the existing layout — read the current implementation to find `col1_w`, `col2_w`, and the font aliases used.
