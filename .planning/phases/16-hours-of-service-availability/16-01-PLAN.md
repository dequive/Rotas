Implement two endpoints:

**GET /availability/drivers**
- Query params: `status: str | None = None` (filter: "available", "hos_warning", "hos_violation", "unavailable"), `limit: int = Query(50, ge=1, le=200)`, `offset: int = Query(0, ge=0)`
- Auth: `require_permission(FLEET_READ)`
- Body: Query all active drivers for the tenant (status="active" on Driver model), then call `driver_availability_summary()` for each. Return paginated list.
- Redis cache key: `av:drivers:{tenant_id}`, TTL 30s, same NX+EX stampede lock pattern as control_tower.
- Since HOS fields are not yet computed (hos_service comes in Plan 02), include `hos_status: "pending"` placeholder in each item for now. Plan 02 will add real HOS data by extending driver_availability_summary.
- Response shape per item: `{driver_id, driver_name, status, available, blockers, warnings, active_trip_id, hos_status}` — `hos_status` is `"pending"` until Plan 02 wires it.

**GET /availability/vehicles**
- Query params: `status: str | None = None` (filter: "available", "in_trip", "in_maintenance", "unavailable"), `limit: int = Query(50, ge=1, le=200)`, `offset: int = Query(0, ge=0)`
- Auth: `require_permission(FLEET_READ)`
- Body: Query all vehicles for the tenant, call `vehicle_availability_summary()` for each. Return paginated list.
- Redis cache key: `av:vehicles:{tenant_id}`, TTL 30s.
- Response shape per item: `{vehicle_id, plate_number, status, available, blockers, warnings, active_trip_id, active_work_order_id}` — derive `computed_status` from blockers: if `vehicle_workshop_blocked` in blocker codes → "in_maintenance"; if `vehicle_assignment_conflict` → "in_trip"; if not available → "unavailable"; else → "available".

For the list queries, use SQLAlchemy `select(Driver).where(Driver.tenant_id == tenant_id, Driver.status == "active").offset(offset).limit(limit)` — do NOT query all rows and filter in Python. Apply optional status filter AFTER computing summaries (cache the full list, return filtered view).

IMPORTANT: The cache stores the full list. Status filter is applied in Python after cache retrieval — this is correct because the list is small (tenants have <200 drivers/vehicles) and TTL is 30s.

Import the service functions: `from app.modules.availability import service as availability_service` and `from app.modules.drivers.models import Driver` and `from app.modules.vehicles.models import Vehicle`.

Use `json.dumps(result, default=str)` for Redis serialization (same as control_tower pattern).
